Request your own key.

Run buttons work out of the box with the shared public key daratechapi; its current limits are shown live in the key checker below. A saved key is stored in this browser only (localStorage) and is never added to copied URLs. No key yet? Request one.

Missing, invalid, disabled or expired keys return 401 / 403; exhausted limits return 429.

Error shape
{
  "status": 429,
  "success": false,
  "creator": "DaraTech",
  "error": "daily request limit reached",
  "message": "daily request limit reached",
  "code": "API_KEY_DAILY_LIMIT_EXCEEDED",
  "hint": "Wait for the daily reset or request a personal key.",
  "contact": "/request-key",
  "contactAction": "request_key",
  "contactLabel": "Request your own key",
  "period": "daily",
  "retryAfter": 3600
}

Read code to handle an error. Optional fields appear only when needed.

401 Missing, invalid or expired API key.

403 Disabled key or blocked origin.

429 Daily, monthly or all-time quota reached; repeated key requests are rate-limited. Reset errors include retryAfter.

503 Key storage unavailable; this does not mean the key is invalid.

400 / 404 / 405 / 409 / 502 Invalid request / not found / unsupported method / duplicate or reviewed request / upstream failure.

Status

Key Checker

Verify a key and view its limits and usage. Checking does not use quota, and exhausted keys still show their usage. Server side, GET /key/info returns the same data using any header or query form above.

Endpoints

Endpoint Groups

Sources provide short playback URLs and descriptive filenames without exposing your API key. Links expire after six hours. Streaming, seeking and downloading do not consume extra quota; deleted, disabled or expired keys stop working immediately. Use Authorization headers for API requests, never keys in URLs.

Open the short URL in your player or browser. Downloads use a descriptive title and episode filename.
